NOTE
----
Speedup was calculated using the sequential execution time:
Speedup = Sequential time / Parallel time

Efficiency was calculated as:
Efficiency = Speedup / Number of threads * 100

Some efficiencies exceed 100% because the separately compiled
sequential program was slower than the 1-thread Pthreads/OpenMP
versions on this WSL2 environment. The measured values are retained
as actual experimental results rather than replacing them with sample
values from the document.
